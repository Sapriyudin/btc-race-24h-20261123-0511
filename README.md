A momentum trend-follower that trades Coinbase Wrapped BTC (cbBTC) minute by minute on $1,000 of paper money. It buys the whole stake at the first rebalance and holds, exiting only on a 5% trailing stop, so it rides an uptrend and caps a crash. Dev window net PnL: +34.94 USDC (1 trade, max drawdown 1.98%).

## Run it
